# Session handoff — GRCS native (android/)
الفرع: main بعد دمج feature/ux-messages-exports · R18 (v5.8.0) · الويب 5.8.0 · سجل النقل: docs/web-spec/PORT.md

## الحالة
- R18: إشعارات الرسائل المحلية (MsgNotifier + MsgWorker 15د)، تفريغ الصادر تلقائياً، UpdatePrompt عند الدخول، ملفاتي + إلغاء التصدير، مزامنة المستفيد بالنبض، شريط التعديلات المعلّقة.
- لم تُجرَّب R14–R18 على جهاز.

## قرارات
- الإشعارات محلية بالفحص (لا FCM)؛ أقل تأخير ~15 دقيقة والتطبيق مغلق، ولا إشعار والتطبيق ظاهر.
- المطابقة الوطنية على جهاز الأدمن فقط.

## مفتوح
- إن أراد ساجد إشعاراً فورياً: FCM + مسار Cloudflare Worker.
- تحسينات لوحة الإدارة (آخر مزامنة لكل مندوب، تنبيه مخيمات متأخرة) لم تُنفَّذ.
- إذن الإشعارات على Android 13+ يُطلب مرة واحدة.
