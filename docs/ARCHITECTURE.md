# وثيقة المعمارية البرمجية: منظومة مخيمات النزوح

### 1. نظرة عامة
يُعد هذا التطبيق نظاماً إلكترونياً متكاملاً يعمل كمنظومة محلية مستقلة لإدارة وتسجيل بيانات النازحين في المخيمات وتتبع حالاتهم الصحية والاجتماعية وسجلات أسرهم بدقة عالية دون الحاجة لاتصال مستمر بالشبكة. يتيح النظام لمسؤولي المخيمات ومدخلي البيانات استيراد وتصدير التقارير الإحصائية والطبية، وإدارة حسابات المستخدمين، والتواصل الداخلي لضمان سرعة الاستجابة ونجاعة العمليات الإغاثية.

---

### 2. المكونات الرئيسية

| الوحدة الوظيفية | الدور والمسؤولية |
| :--- | :--- |
| **محرك التوجيه وإدارة الواجهات** | إدارة تنقل المستخدم بين الشاشات المختلفة دون إعادة تحميل الصفحة، والتحكم بظهور عناصر الملاحة والشريط السفلي. |
| **وحدة إدارة الهوية والمصادقة** | التحقق من هوية المستخدمين، إدارة الجلسات المحلية وتحديد الصلاحيات بناءً على أدوار المستخدمين (مدير نظام / مندوب مخيم). |
| **محرك التخزين المحلي** | إدارة قاعدة البيانات المحلية على المتصفح للتعامل مع السجلات، الأسر، المخيمات، الرسائل، وسجل التغييرات. |
| **وحدة إدارة الأفراد والأسر** | استعراض، إضافة، وتحديث بيانات الأشخاص والأسر، وحساب الأعمار وتصنيف الفئات العمرية والحالات الصحية تلقائياً. |
| **وحدة الاستيراد والمعالجة الدفعية** | قراءة وتفكيك ملفات البيانات الخارجية، مطابقة الأعمدة تلقائياً، وإدخال البيانات على دفعات متتالية لتفادي تجمد الواجهة. |
| **وحدة التصدير والتقارير** | تصفية البيانات المتقدمة وتوليد التقارير المخصصة بصيغ جداول بيانات وقابلة للطباعة المباشرة. |
| **وحدة الرسائل والتواصل** | توفير نظام مراسلة داخلي لإدارة المحادثات وتبادل التحديثات والتعليمات بين الإدارة والمندوبين. |
| **وحدة التدقيق والرقابة** | تسجيل وتتبع كافة العمليات والتعديلات التي تجري على النظام وتربيطها بمسؤولية المستخدم وزمن التنفيذ. |
| **وحدة لوحة القيادة والتحليلات** | تجميع البيانات الإحصائية وتوليد مؤشرات الأداء والرسوم البيانية التفاعلية للحالات الخاصة والتوزيع الديموغرافي. |

### 3. تدفق البيانات

#### المدخلات:
* **بيانات تفاعلية من المستخدم:** مدخلات الاستمارات اليدوية (إضافة/تعديل فرد، إنشاء حساب، كتابة رسالة، إدخال بيانات مخيم).
* **ملفات خارجية:** رفع ملفات جداول البيانات بصيغ Excel أو CSV لاستيراد البيانات الجماعية.

#### المعالجة:
1. **التحقق والتشفير:** فحص صحة البيانات المدخلة وتشفير كلمات المرور عبر خوارزميات التجزئة التراكمية.
2. **الحساب والتصنيف:** احتساب العمر بناءً على تاريخ الميلاد وتحديد الفئة (طفل، بالغ، مسن) وتحديد الحالة الاستثنائية (حمل، مرض مزمن، إعاقة).
3. **التجميع والدفعات:** تجزئة الملفات المرفوعة إلى مجموعات صغيرة لمعالجتها عبر مهام خاملة في المتصفح لضمان استقرار الأداء.
4. **التدوين والرقابة:** حفظ البيانات المعالجة داخل الجداول المختصة وتدوين حدث التغيير في سجل التدقيق.

#### المخرجات:
* **عرض مرئي:** تحديث بطاقات الإحصائيات والقوائم والرسوم البيانية في الواجهة فورياً.
* **ملفات تقارير:** استخراج ملفات مقروءة بصيغ Excel و CSV أو مستندات جاهزة للطباعة.
* **إشعارات وتنبيهات:** رسائل توجيهية واستجابات بصرية تخبر المستخدم بنجاح العمليات أو وجود أخطاء.

## ⚠️ القيود التقنية والمعمارية

- التخزين محلي فقط (localStorage) — حد ~5–10 MB
- يعمل بدون خادم في الوضع الأساسي
- التشفير: XOR cipher (حماية من الفضول، ليس تشفير قوي)
- كل الشبكة مُغلّفة بـ try/catch مع fallback للوضع الأوفلاين
- لا secrets في الكود — التوكنات مشفرة ومخزنة محلياً
