# خطة التطبيق الأصلي — النسخة المعاد ترتيبها (واجهة أولاً)

القرار: التطبيق الأصلي ينقل تصميم نسخة الويب كما هو بالضبط (ألوان، بطاقات، ترويسة، تبويبات، أماكن الميزات) ثم يتفوق عليها بالسرعة والسلاسة وصلاحيات الأندرويد. اللغة Kotlin (على نفس منصة جافا/أندرويد) مع Jetpack Compose.
الترتيب الجديد: **الواجهة قبل أي ميزة جديدة**. الوظائف المنفّذة في المراحل 1–3 (مزامنة، دمج، حسابات، تصدير، سلة، سجل، استعلامات، مكررات، إدخال سريع) تبقى كما هي وتُنقل إلى أماكنها الصحيحة.

## مرجع التصميم (من index.html، لا اجتهاد)
- **الألوان:** Navy `#0F2B52` (داكن `#0A1D38`، فاتح `#1E4272`) • Teal `#0E7490` (فاتح `#0891B2`، داكن `#0C5A73`) • خلفية `#F1F5F9` • سطح `#FFFFFF` و`#F8FAFC` • نص `#1E293B` • خافت `#64748B` • حد `#E2E8F0`.
- **الدلالات:** danger `#DC2626` • warning `#D97706` • حوامل `#EA580C` • success `#059669` • purple `#7C3AED` • blue `#2563EB` • ذهبي الحرج `#E9B44C`؛ درجات الهشاشة: حرجة ذهبي، عالية `#E0663A`، متوسطة `#3E8FB0`، مستقرة `#8594A8`.
- **الوضع الليلي «ليل الخيام»:** Navy `#0B1F3A` • خلفية `#07111F` • سطح `#0E1B2E` • Teal مضيء `#22B8D6` • نص `#E3ECF6` (كاملة في CSS الويب).
- **الخط:** Cairo (عربي + لاتيني). **الأبعاد:** بطاقة 16 • زر 12 • حقل 10 • حبّة 999 • ترويسة 60 • تبويب سفلي 64 • عرض المحتوى الأقصى 640.
- **التنقل السفلي حسب الدور (مطابق للويب):** أدمن: الرئيسية، المخيمات، الرسائل، الحسابات، الإعدادات • مندوب: الرئيسية، الأفراد، الرسائل، تصدير، الإعدادات • مدخل بيانات: الرئيسية، الأفراد، الإعدادات • مستفيد: واجهته الخاصة.
- **أنماط المكونات:** ترويسة كحلية بشعار وعنوانين وشارة اتصال وبحث • بطاقات إحصاء بحافة ملوّنة وأيقونة وحلقة تقدم • شريط هشاشة مجزّأ • أشرطة جودة لكل مخيم • بطاقات إعدادات مجمّعة بعناوين وأيقونات.

**آلية التحقق (لأنني لا أرى الجهاز):** اختبارات لقطات (Paparazzi) على CI تولّد صورة لكل شاشة بالبيانات التجريبية وتُرفع كـartifact؛ تراها وتعلّق قبل المتابعة. لا ينتقل العمل لخطوة قبل موافقتك على لقطة السابقة.

**أين تتفوق على الويب بحكم أنه تطبيق أصلي:** إذن الإشعارات والتخزين وملفات المشاركة والمشاركة مع تطبيقات أخرى، قفل بالبصمة اختيارياً، عمل دون اتصال أسرع بقاعدة محلية، نسخ احتياطي تلقائي بجدولة النظام، دون قيود المتصفح.
