# v5.0.0

## الإضافات
- مطابقة كشف وطني شامل (تكميل الحقول الفارغة فقط).
- رسوم الرئيسية: ترتيب المخيمات بالسكان، الحالات الحرجة، الهرم السكاني.
- مفتاحا اهتزاز خفيف وصوت نقرة.

## المميزات
- الرئيسية بنفس بطاقات الويب وتسمياتها وترتيبها (18 للمدير، 19 للمخيم) وكلها قابلة للضغط.
- تفاصيل المخيم للمدير: معلومات المخيم وأزرار الأفراد والاستيراد والكشف.
- الإعدادات بترتيب الويب وأسلوبه.
- شاشة المخيمات بتصميم الويب: أدوات عامة وبطاقات بأرقام واكتمال وأزرار.

## الإصلاحات
- إعادة ترتيب الواجهات لتطابق الويب بدل التصميم المبتكر السابق.
