# v4.0.0 — النسخة الأصلية (Android)

## الإضافات
- تطبيق أندرويد أصلي (Kotlin + Compose) يحل محل نسخة WebToApp ويُثبَّت فوقها (نفس المعرّف والتوقيع).
- تقرير المساعدات، إدارة المخيمات للأدمن (إنشاء وإعادة تسمية)، صندوق صادر للرسائل دون اتصال.
- النسخ الاحتياطي في مجلد باسم التطبيق مع قائمة واستعادة داخل التطبيق.

## المميزات
- نفس حسابات المناديب والمستفيدين وبياناتهم؛ Firestore هو المصدر الوحيد للحقيقة.
- عمل دون اتصال مع دمج آمن على مستوى الفرد وإشارات مزامنة تفهمها نسخة الويب.
- مؤشر الهشاشة مع تفسير نص المأوى، شارات المستوى على صفوف الأسر، جودة البيانات، الاستيراد، نقل الأسرة.
- عدّاد استهلاك الحصة المجانية على الجهاز.

## الإصلاحات
- حذف ربّ الأسرة يحذف حساب المستفيد المرتبط به.
- إزالة اسم المشرف الإقليمي السابق من كل الواجهات (نسخة الويب v3.6.1).
