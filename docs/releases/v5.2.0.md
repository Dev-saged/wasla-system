# v5.2.0

## الإضافات
- مركز الجودة بقواعد الويب (هويات مكررة، بلا هوية، تواريخ مشبوهة، هويات غير صحيحة بخانة التحقق، مواليد تجاوزوا السنتين) مع فتح نموذج الفرد للإصلاح.
- شاشة الاستيراد: بطاقة الفورمة الموحّدة، منطقة اختيار الملف، رفع كشف تصنيفي.

## المميزات
- حقول الإدخال بعنوان فوق الحقل كالويب في كل النماذج.
- الإدخال السريع: بطاقة الأسرة، أزرار الصلة، بطاقة الحقول، زر «حفظ والتالي» ثابت أسفل الشاشة.
- معلومات المخيم: رقم المخيم، بطاقة التواريخ، ملاحظات عامة.
- منشئ الاستعلامات: شريط النتيجة (تصدير/حفظ) وبطاقات الأفراد.
- الأسماء المتشابهة: شرح وحالة فارغة كالويب.
- الرسائل للمندوب: «المركز الرئيسي» و«رسائل المستفيدين».

## الإصلاحات
- مطابقة تسميات وترتيب الشاشات مع الويب.
