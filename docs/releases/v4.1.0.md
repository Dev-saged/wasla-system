# v4.1.0 — واجهة التطبيق الأصلي بتصميم نسخة الويب

## الإضافات
- ترويسة كحلية ثابتة بشعار وشارة اتصال، وتبويب سفلي حسب الدور (مسؤول / مندوب / مدخل بيانات / مستفيد) مطابق للويب.
- شاشة الإعدادات كبطاقات: المزامنة، النسخ الاحتياطي، الحماية من فقدان البيانات، أدوات البيانات، الإدارة، المظهر، حول التطبيق.
- اختيار المظهر: تلقائي / فاتح / ليلي («ليل الخيام»).

## المميزات
- بطاقات إحصاء بحافة ملوّنة وعدّاد متحرك، شريط مؤشر الهشاشة، أشرطة جودة البيانات لكل مخيم.
- خط Cairo وألوان الويب نفسها (كحلي وتيل)، وحركة دخول ناعمة تحترم «إزالة الحركات».
- الحسابات بتبويبات وبحث وبطاقات حالة، والرسائل بأيقونات وشارات، والمخيمات بطاقات تفتح الأسر مباشرة.

## الإصلاحات
- أيقونات شريط الحالة تبقى بيضاء فوق الترويسة الكحلية في الوضعين.
