# v5.1.0

## الإضافات
- زر «تحميل هذا التصنيف» في قائمة الأفراد.
- تبويب المستفيدين في الحسابات بنفس تصميم الويب.

## المميزات
- نموذج الفرد مقسّم لبطاقات كالويب: البيانات الأساسية، الأسرة، الزوج، التواصل، الحالة الصحية، الملاحظات.
- شاشة المساعدات بملخص الويب (المستحقون/المستلمون/الفترة).
- التصدير كـ«تصدير تقرير مخصص» بأعمدة وتصنيفات قابلة للاختيار.

## الإصلاحات
- مطابقة ترتيب وتسميات الحسابات والتصدير والمساعدات مع الويب.
