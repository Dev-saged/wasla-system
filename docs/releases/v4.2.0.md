# v4.2.0 — إدارة المخيم وقوالب الاستيراد

## الإضافات
- معلومات المخيم: المسؤول ونائبه ومدخل البيانات والمنطقة والملاحظات، تُطبَّق عند الجميع.
- سجل نقل الأسر بين المخيمات.
- تشخيص المزامنة: حالة كل مخيم، التعديلات المعلّقة، الحصة اليومية للجهاز، وإعادة سحب كامل.
- إفراغ بيانات المخيم وحذفه نهائياً (للمسؤول): نسخة احتياطية إلزامية ثم سلة المحذوفات ثم تأكيد بكتابة اسم المخيم.
- مطابقة أعمدة الاستيراد يدوياً مع حفظها كقالب بصمة يُطبَّق تلقائياً على الملفات المماثلة.

## المميزات
- كل صفحات الأدوات (الهشاشة، الجودة، الاستعلامات، المتشابهة، الإدخال السريع، السلة، السجل، الاستيراد، التصدير، المساعدات) بتصميم البطاقات والأزرار الموحّد.

## الإصلاحات
- تسمية سجل نقل الأسرة وإفراغ المخيم وحذفه في سجل النشاط.
